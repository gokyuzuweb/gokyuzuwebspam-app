1

Ön gereksinimler

Kuruluma başlamadan önce şunları doğrulayın:

  • WHM sürümü 110+ (test: 136.0.32) — cat /usr/local/cpanel/version
  • Root SSH erişimi
  • Exim + Apache SpamAssassin aktif (WHM > Service Manager)
  • Sistem yedeği (opsiyonel ama önerilir)
Hazır olmadıysanız: WHM > Home > Backup > Backup Configuration'dan tam sunucu yedeği alın veya sanal makine snapshot'ı oluşturun. Ancak bu paket cPanel yapılandırmasına dokunmadığı için pratikte yedeğe ihtiyaç duymayacaksınız.
2

MongoDB kurulumu (yoksa)

GokyuzuWebSpam karantina, liste ve log verilerini yerel MongoDB'de tutar. Sunucuda MongoDB yoksa şu komutları çalıştırın:

cat >/etc/yum.repos.d/mongodb-org-7.0.repo <<'EOF'
[mongodb-org-7.0]
name=MongoDB Repository
baseurl=https://repo.mongodb.org/yum/redhat/$releasever/mongodb-org/7.0/x86_64/
gpgcheck=1
enabled=1
gpgkey=https://www.mongodb.org/static/pgp/server-7.0.asc
EOF
yum install -y mongodb-org
systemctl enable --now mongod
MongoDB sadece 127.0.0.1'de dinler. MySQL/MariaDB'nize etkisi yoktur.
3

Paketi sunucuya aktarın

Yerel makinenizden veya panelden aldığınız whm-plugin dizinini WHM sunucusunun /root altına kopyalayın:

# Yerel makineden
scp -r whm-plugin root@sunucunuz.com:/root/

# Sunucuya bağlanın
ssh root@sunucunuz.com
cd /root/whm-plugin
chmod +x install.sh uninstall.sh mailshieldctl
4

Dry-run + gerçek kurulum

Önce hiçbir dosya yazmadan neyin nereye kopyalanacağını görün:

./install.sh --dry-run

Beğendiğinizde gerçek kurulumu başlatın:

./install.sh
Kurulum sırasında hiçbir mevcut cPanel dosyası yeniden yazılmaz. cp -n (no-clobber) modu ile yalnızca eksik dosyalar eklenir.

Kurulum ne yapar?

  • /usr/local/mailshield/ — uygulama kaynakları
  • /etc/mailshield/ — yapılandırma dosyaları
  • /var/log/mailshield/ — loglar
  • /var/cpanel/apps/mailshield.conf — WHM AppConfig
  • systemd: mailshield-api, mailshield-milter (BAŞLATILMAZ), mailshield-quarantine.timer

6

Milter bağlantısı (OPT-IN — gerçek koruma bu adımda başlar)

Kurulumdan sonra GokyuzuWebSpam gözlem modundadır — dashboard çalışır, karantina/liste yönetimi manuel yapılabilir; ancak Exim ile bağ kurmadıkça gerçek mail akışına dokunmaz.

Gerçek mail süzmeyi başlatmak için:

Adım A — milter servisini başlatın:

systemctl enable --now mailshield-milter.service

Adım B — Exim'e milter'ı tanıtın:

  • WHM > Exim Configuration Manager > Advanced Editor
  • Şu satırı ekleyin:
milters=inet:127.0.0.1:33333
  • Save butonuna basın

Adım C — Exim yapılandırmasını yeniden derleyin:

/scripts/buildeximconf
/scripts/restartsrv_exim

Doğrulama:

tail -f /var/log/mailshield/milter.log
# başka bir terminalden test maili
echo "test spam viagra" | mail -s "Test" root@localhost
Cayma (rollback): Bir sorun olursa milters= satırını Advanced Editor'den silin, 
/scripts/buildeximconf && /scripts/restartsrv_exim
çalıştırın. cPanel önceki durumuna geri döner.
7

Motor entegrasyonları

Apache SpamAssassin

Zaten WHM > Service Manager'da yönetilir. GokyuzuWebSpam yalnızca spamc komutunu çağırır — SA yapılandırmanız değişmez.

ClamAV (opsiyonel)

yum install -y clamav clamav-server clamav-update clamav-scanner-systemd
freshclam
systemctl enable --now clamd@scan
mailshieldctl engine enable clamav

DCC (opsiyonel)

yum install -y dcc || cpan -T DCC::Client
mailshieldctl engine enable dcc

Vipul's Razor (opsiyonel)

yum install -y razor-agents
razor-admin -create
razor-admin -register
mailshieldctl engine enable razor

AI Sınıflandırma (opsiyonel)

/etc/mailshield/mailshield.conf dosyasına Emergent LLM anahtarınızı yazın:

[ai]
provider           = emergent
model              = claude-sonnet-4-5
emergent_llm_key   = sk-emergent-...

Panelde Ayarlar → AI Sınıflandırma toggle'ını açın; model seçicisinden Claude Sonnet 4.5 / GPT-5.2 / Gemini 3 Flash arasında geçiş yapın.

8

cPanel kullanıcıları için MailControl

Kullanıcılar için MailControl arayüzü otomatik eklenir:

  • cPanel > Email > GokyuzuWebSpam MailControl
  • Kullanıcı yalnızca kendi karantinasını görür (virtusers eşleşmesi ile yalıtım)

Belirli reseller/paket için gizlemek isterseniz:

  • WHM > Feature Manager > "GokyuzuWebSpam MailControl" satırını istediğiniz Feature List'ten çıkarın.
9

Bildirim & AI & PDF testleri

Slack + Telegram uyarıları

Panel > Bildirimler sekmesi:

  • Slack Webhook URL girin, toggle'ı açın, Slack Test Bildirimi butonuna basın
  • Telegram için BotFather'dan aldığınız token + chat ID girin, test edin
  • "Tehdit Alarmı Simüle Et" — karantinadan gerçek bir kayıt ile alert gönderir

AI sınıflandırma

  • Ayarlar > AI Sınıflandırma toggle'ı açık olmalı
  • Kurallar > Kural Test Cihazı → örnek mesajı Claude/GPT/Gemini ile skorlayın

Haftalık PDF rapor

  • Raporlar sekmesi > Şimdi İndir — PDF anında üretilir
  • E-posta adresi girip E-posta ile Gönder — sunucudaki /usr/sbin/sendmail üzerinden yollanır
  • Otomatik zamanlama: Ayarlar > Bildirimler > Rapor Sıklığı
10

Cayma / Kaldırma

cd /root/whm-plugin
./uninstall.sh
  • GokyuzuWebSpam servisleri durdurulur
  • AppConfig kaydı silinir
  • /usr/local/mailshield kaldırılır
  • /etc/mailshield/ ve /var/log/mailshield/ KORUNUR (denetim için)
  • Exim / SpamAssassin / cPanel yapılandırmalarına HİÇ dokunulmaz

Milter'ı Exim'den de temizlemek isterseniz:

# WHM > Exim Configuration Manager > Advanced Editor
# milters=... satırını silin, Save
/scripts/buildeximconf && /scripts/restartsrv_exim
